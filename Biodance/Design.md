# Biodance Design System

> 목적: 완성된 메인페이지의 시각 언어와 UI 동작을 서브페이지에서도 일관되게 재사용하기 위한 구현 기준서  
> 기준 파일: `Biodance/css/index.html`, `Biodance/css/main.css`  
> 보조 스타일 파일: `Biodance/css/neo-brutalism.css`  
> 작성 기준: 저장소의 HTML/CSS 소스에서 확인 가능한 규칙만 기록한다. 화면이나 코드에서 확인되지 않은 값은 임의로 보충하지 않는다.

---

## 1. Project Overview

Biodance 리뉴얼 사이트는 스킨케어 제품과 브랜드 콘텐츠를 소개하고, 사용자가 제품 정보·프로모션·브랜드 콘텐츠를 탐색하도록 구성된 커머스형 웹사이트다.

메인페이지의 주요 콘텐츠 흐름은 다음과 같다.

1. 프로모션 안내 바
2. 브랜드 로고와 주요 내비게이션(GNB), 유틸리티 아이콘
3. 메인 비주얼 배너(Swiper)
4. 카테고리 바로가기
5. Best Sellers 제품 목록
6. 브랜드 영상
7. Woni's Pick 등 추천 콘텐츠
8. 하단 콘텐츠 및 푸터

**서브페이지 적용 원칙:** 페이지 목적에 맞게 콘텐츠는 달라질 수 있지만, 공통 헤더·내비게이션·타이포그래피·컬러·간격·버튼 상태는 메인페이지의 규칙을 우선 재사용한다.

## 2. Brand Identity

### 확인된 시각적 특징

- 민트 계열(`--teal-mint`)과 핑크 계열(`--brand-pink`, `--brand-rose`)을 브랜드 포인트로 사용한다.
- 흰색과 크림색 배경, 차콜 텍스트를 함께 사용해 제품 이미지와 정보를 읽기 쉽게 구성한다.
- 제품 패키지·제품 이미지와 모델/브랜드 영상을 주요 시각 콘텐츠로 활용한다.
- Pretendard Variable을 기본 글꼴로 지정한다.
- 프로모션, 제품 정보, 추천 콘텐츠를 구분된 섹션으로 나누어 쇼핑 탐색 흐름을 만든다.

### 디자인 해석

민트와 핑크의 대비는 브랜드의 생기 있는 인상을 만들고, 넓은 제품 이미지와 정돈된 정보 영역은 스킨케어 제품을 비교·탐색하기 쉽게 돕는다. 이는 소스에 사용된 색상과 콘텐츠 구성에 근거한 디자인 해석이다.

## 3. Design Principles

1. **브랜드 컬러는 역할에 맞게 사용한다.** 민트는 강조/상태 표현, 핑크는 브랜드 표면과 주요 액션에 사용된 기존 패턴을 따른다.
2. **제품이 콘텐츠의 중심이 되게 한다.** 제품 이미지의 비율과 크롭을 임의로 바꾸거나 장식 요소를 과도하게 추가하지 않는다.
3. **정보 위계를 유지한다.** 섹션 제목 → 보조 설명 → 제품명/가격/리뷰처럼 정보의 중요도에 맞춰 구분한다.
4. **공통 UI를 재사용한다.** 페이지마다 헤더, 버튼, 링크, 카드의 모양과 상태를 새로 발명하지 않는다.
5. **반응형은 단순 축소가 아니다.** 화면 폭에 따라 내비게이션과 콘텐츠 배열을 전환하고, 터치 환경에서 조작 가능한 크기와 간격을 유지한다.
6. **기존 메인페이지를 기준으로 한다.** 서브페이지 구현을 위해 메인페이지의 기존 HTML/CSS를 수정하거나 디자인을 변경하지 않는다.

## 5. Typography

### Font

- 기본 변수: `--font-primary`
- 선언값: `"Pretendard Variable", sans-serif`
- HTML에서 Pretendard Variable CSS 파일을 불러온다.
- 한글과 영문이 섞인 제목/내비게이션/상품 정보도 동일한 기본 글꼴 체계를 우선 사용한다.

### 크기와 굵기 적용 규칙

메인 CSS에는 컴포넌트와 반응형 구간별로 서로 다른 글자 크기·굵기·행간이 지정되어 있다. 모든 텍스트에 적용되는 하나의 공통 크기표로 단순화하지 않는다.

- GNB: 데스크톱 기준 20px, 굵기 400으로 지정된 최종 헤더 규칙이 있다.
- 모바일 GNB 링크: 16px, 행간 24px로 지정된 규칙이 있다.
- 히어로 배너의 카피는 데스크톱에서 컨테이너 폭(`cqw`)에 비례하고, 모바일에서는 `clamp()`로 크기를 조절한다.
- 상품명, 가격, 리뷰, 섹션 제목은 해당 컴포넌트의 기존 선택자 규칙을 확인해 적용한다.

**서브페이지 규칙:** 새 폰트나 임의의 크기 체계를 도입하지 않는다. 유사한 역할의 기존 컴포넌트 값을 먼저 재사용하고, 새로운 텍스트 역할이 필요할 때만 메인 CSS의 위계와 비례 관계를 참고해 추가한다.

## 6. Layout & Spacing

### Header

- 프로모션 바는 민트 배경이며 소스에서 높이 32px로 지정되어 있다.
- 데스크톱 헤더 본문은 80px 규칙이 선언되어 있다.
- 모바일 구간(`max-width: 1024px`)에서는 헤더 본문 높이 58px 규칙이 최종 조정 구간에 존재한다.
- 헤더 내부는 flex를 사용해 로고, GNB, 유틸리티 아이콘을 가로 정렬한다.
- 데스크톱 GNB는 헤더 안에서 로고와 유틸리티 사이에 배치되며, 모바일에서는 메뉴 패널로 전환된다.

### Hero

- 메인 비주얼은 Swiper로 구성한다.
- 데스크톱 비주얼은 `aspect-ratio: 1920 / 800` 규칙이 있으며 이미지에 `object-fit: cover`를 적용한다.
- 모바일은 별도의 `.mo` 이미지를 표시하고 데스크톱용 `.pc` 이미지를 숨기는 방식이다.
- 배너 카피는 이미지 위에 absolute로 배치되며 데스크톱/모바일의 위치와 크기 규칙이 분리되어 있다.

### Content sections

- 카테고리, 베스트 상품, 브랜드 영상, 추천 상품 등은 목적별 section으로 분리한다.
- 상품 반복 목록은 grid 기반 배치를 사용한다. 서브페이지에서 카드 개수와 열 수를 바꿀 때도 카드 간격과 이미지 비율을 함께 확인한다.
- 레이아웃 수치는 CSS에 실제 적용된 선언을 우선한다. 이 문서에 없는 컨테이너 최대 너비나 공통 간격 수치를 새로 가정하지 않는다.

## 7. Components

### 7.1 Site header

구성: `.site-header` → `.promo-bar` → `.header-main` → `.header-inner` → `.brand-logo`, `.main-nav`, `.header-actions`.

- 프로모션 바의 좌우 화살표는 버튼으로 제공하고, 안내 문구는 중앙에 배치한다.
- 로고는 이미지 요소를 사용한다.
- GNB는 링크 목록으로 구성한다.
- 검색/계정 등 유틸리티는 `.icon-link`로 통일한다.
- 모바일 메뉴는 `.menu-toggle` 및 `.main-nav.is-open` 상태를 사용한다.
- 데스크톱 메가 메뉴가 존재하는 경우 기존 구조와 상태 클래스를 재사용한다.

### 7.2 Hero slider

- Swiper의 `.swiper`, `.swiper-wrapper`, `.swiper-slide` 구조를 사용한다.
- 페이지네이션과 이전/다음 버튼을 제공한다.
- 이미지에는 콘텐츠를 설명하는 대체 텍스트를 작성한다.
- 데스크톱과 모바일에서 서로 다른 배너 이미지를 사용할 수 있도록 `.pc` / `.mo` 구분을 유지한다.

### 7.3 Category shortcut

- 이미지와 텍스트를 하나의 링크(`.category-item`)로 묶는다.
- 이미지가 장식 목적이면 빈 alt를 사용하고, 링크 텍스트가 이동 목적을 설명하도록 한다.

### 7.4 Product card

- 제품 이미지는 `.best-product-image` 안에 배치한다.
- 제품명, 판매가, 할인율, 정가, 리뷰 정보는 `.best-product-info` 영역에서 구분한다.
- ONLY/BEST/수량 등의 라벨은 이미지 위에 겹쳐 배치하는 기존 구조를 따른다.
- 가격 정보는 할인 가격과 정가를 시각적으로 구분하고, 할인율은 별도 요소로 표시한다.
- 상품 카드의 이미지 비율과 텍스트 영역을 페이지마다 임의로 다르게 만들지 않는다.

### 7.5 Brand video / Pick content

- 영상은 `.brand-video`와 source 요소로 구성하며 autoplay 사용 시 muted와 playsinline 설정을 유지한다.
- 추천 콘텐츠는 모델 이미지 영역과 상품 목록 영역을 구분한다.
- 콘텐츠가 없는 서브페이지에 장식 목적으로 영상/모델 영역을 무리하게 추가하지 않는다.

### 7.6 Buttons and links

- 이동에는 `<a>`, 현재 페이지에서 실행되는 동작에는 `<button type="button">`을 사용한다.
- 아이콘 버튼에는 목적을 설명하는 `aria-label`을 제공한다.
- 링크와 버튼의 클릭 영역을 아이콘이나 글자 자체에만 한정하지 않는다.
- 기존 디자인의 버튼 배경/테두리/모서리/크기 규칙을 우선 재사용한다.

## 8. Interaction

### Hover / Focus

- GNB 링크는 hover 및 focus-visible에서 기존 CSS에 지정된 색상/투명도 변화를 사용한다.
- 일부 헤더 규칙에서는 링크 hover/focus 시 투명도를 낮추는 방식이 확인된다.
- 키보드 사용자를 위해 `:focus-visible`을 유지한다.
- 히어로 이전/다음 버튼에는 차콜 계열 outline과 outline-offset을 사용하는 focus-visible 규칙이 있다.

### Active

- Swiper 컨트롤은 이전/다음 버튼과 페이지네이션을 통해 배너를 변경한다.
- 버튼의 active 상태는 눌림 피드백을 제공하되 레이아웃을 크게 흔들지 않는다.
- 모바일 GNB의 활성 링크는 민트 배경과 흰색 글자 상태가 정의되어 있다.

### Motion

- 기존 CSS의 transition 및 `prefers-reduced-motion: reduce` 대응을 확인하고 유지한다.
- 새 인터랙션을 추가할 때 과도한 이동/확대 효과를 넣지 않는다.
- 자동 재생 콘텐츠는 사용자가 콘텐츠를 읽고 조작하는 데 방해가 되지 않도록 한다.

## 9. Responsive Rules

### Breakpoints found in source

| 조건 | 확인된 용도 |
|---|---|
| `max-width: 1024px` | 모바일/태블릿 헤더 전환, PC/모바일 이미지 전환, 히어로 배너 조정 |
| `min-width: 1025px` | 데스크톱 전용 헤더/히어로 카피 규칙 |
| `min-width: 701px` and `max-width: 1024px` | 태블릿 폭에서 로고와 유틸리티 아이콘 크기 조정 |
| `max-width: 700px` | 모바일 전용 내비게이션 및 콘텐츠 규칙 |
| `max-width: 600px` | 일부 작은 화면 콘텐츠 조정 |
| `max-width: 420px`, `360px` | 매우 좁은 화면에서 헤더/요소 간격 조정 |
| `max-width: 1499px`, `1500px` 관련 규칙 | 중간 데스크톱 폭의 일부 레이아웃 조정 |

### Implementation rules

- 1024px 이하에서는 PC 배너 대신 모바일 배너 이미지를 사용한다.
- 모바일에서는 GNB를 기본적으로 감추고 메뉴 토글로 열 수 있게 한다.
- 700px 이하에서는 메가 메뉴를 숨기고 모바일용 내비게이션 상태를 사용한다.
- 701~1024px 구간에서는 로고와 유틸리티 아이콘 크기를 `clamp()`로 유동 조절하는 규칙이 있다.
- 작은 화면에서 텍스트가 겹치거나 아이콘/로고가 충돌하지 않도록 flex 간격, 최소 너비, 줄바꿈을 확인한다.
- 이미지가 잘리는 것이 의도된 경우에만 `object-fit: cover`를 사용하고, 제품 패키지처럼 전체 노출이 필요한 이미지에는 기존 컴포넌트의 표시 방식을 확인한다.

## 10. Do & Don't

### DO

- [ ] 새 페이지를 만들기 전에 `main.css`에서 같은 역할의 컴포넌트 규칙을 찾는다.
- [ ] 컬러는 `:root`의 primitive/semantic 변수를 우선 사용한다.
- [ ] 기본 글꼴은 `--font-primary`를 사용한다.
- [ ] 공통 헤더, GNB, 푸터 및 상품 카드 구조를 재사용한다.
- [ ] 링크는 실제 리뉴얼 프로젝트 내부 페이지 또는 내부에서 정의한 경로로 연결한다.
- [ ] 외부 브랜드 공식몰로 연결하지 않는다. 외부 링크가 필요한 경우 사용자가 별도로 승인한 목적지만 사용한다.
- [ ] 반응형 구간별로 PC/태블릿/모바일에서 직접 확인한다.
- [ ] 키보드 focus-visible과 버튼의 접근성 이름을 제공한다.
- [ ] 이미지 alt, 제목 계층, 버튼/링크의 시맨틱 의미를 지킨다.

### DON'T

- [ ] 메인페이지의 기존 디자인을 임의로 변경하지 않는다.
- [ ] 기존 변수와 무관한 새 브랜드 컬러를 임의로 추가하지 않는다.
- [ ] 근거 없는 폰트 크기, 간격, 컨테이너 너비를 만들어 공통 규칙처럼 사용하지 않는다.
- [ ] 페이지마다 서로 다른 헤더/GNB 스타일을 만들지 않는다.
- [ ] 실제 동작이 없는 요소를 버튼처럼 보이게 만들지 않는다.
- [ ] 모든 클릭 링크를 기존 Biodance 공식 사이트 주소로 연결하지 않는다.
- [ ] `main.css`의 중복 선언 중 일부만 보고 앞선 값을 최종값으로 단정하지 않는다.
- [ ] 데스크톱 CSS가 모바일에 영향을 주거나 반대로 모바일 CSS가 데스크톱을 깨뜨리지 않도록 범위와 미디어쿼리를 확인한다.
