# New 상품 서브페이지 설계

## 페이지 목적
바이오던스의 신제품 정보를 소개하는 상품 상세 서브페이지.

## 기준
- 기존 이벤트 서브페이지의 상단 제목 스타일과 정렬 방식을 참고한다.
- 공통 헤더, 푸터, Pretendard Variable 및 기존 디자인 토큰을 재사용한다.
- 기존 메인페이지와 다른 서브페이지 파일은 수정하지 않는다.

## 레이아웃
- 상단 제목: `New`, 가운데 정렬, 42px, 굵기 600, 행간 1.
- 제목 영역: 이벤트 페이지와 동일하게 상단 패딩 120px, 영역 높이 220px.
- 상품 전체 프레임: 가로 1476px.
- 왼쪽 이미지 프레임: 857 × 900px, 왼쪽 배치, 현재 임시 이미지 영역.
- 오른쪽 상품 설명 프레임: 623 × 900px, 배경 `var(--neutral-cream)`.
- 상품 설명 프레임 내부 콘텐츠는 왼쪽 정렬.

## 상품 설명
### 제목
- 텍스트: 캐비어 PDRN / 듀얼 겔 토너 패드 60pads
- 크기: 40px
- 굵기: 600 (Small Bold에 대응)
- Line Height: normal (Auto)

### 설명
- 텍스트:
  바이오던스의 겔링 노하우로 완성한
  캐비어수와 고순도 PDRN을 한 장에 담은
  닦토+팩토 2in1 듀얼 패드
- 크기: 25px
- 굵기: 500 (Medium)
- Line Height: normal (Auto)

### 텍스트 그룹
- 제목과 설명을 하나의 그룹 프레임에 배치한다.
- 그룹 방향: 세로
- Gap: 36px

## 구현 파일
- `new.html`: 새 상품 상세 페이지 구조
- `new.css`: 새 페이지 전용 스타일
- `New-Design.md`: 본 페이지 설계 기준

## 크기 확인 메모
요청된 두 내부 프레임의 너비 합은 857px + 623px = 1480px로, 상위 프레임 1476px보다 4px 크다. 데스크톱에서는 각 내부 프레임의 요청 크기를 우선 유지하며, 1512px 이하에서는 비율을 유지해 축소하도록 구성한다.

## 상품 평점 영역
- 상품 전체 프레임은 가로 방향 자동 레이아웃에 해당하는 Grid/Flex 레이아웃이며, 높이는 내부 콘텐츠를 기준으로 자동(Hug) 결정한다.
- 상품 설명 아래 평점 행을 추가하고 설명과의 세로 간격은 14px로 맞춘다.
- 별 아이콘: 16 × 16px.
- 별점 `5.0`: 20px, 굵기 600, 별과 간격 4px.
- 리뷰 수 `(435)`: 20px, 굵기 500, 별점과 간격 8px.
- `더 알아보기`: 16px, 굵기 500, 리뷰 수와 간격 16px.
- 오른쪽 화살표: 24 × 24px, 텍스트와 간격 4px.


## 할인 및 가격 영역
- 별점 행 아래 36px 간격으로 가격 행을 배치한다.
- 할인율 프레임: 85 × 40px, Corner Radius 9999px.
- 할인율 `15%`: 25px, 굵기 600 (Small Bold에 대응), Line Height Auto.
- 판매가 `22,000원`: 30px, 굵기 600 (Small Bold에 대응), Line Height Auto.
- 정가 `26,000원`: 25px, 굵기 600 (Small Bold에 대응), Line Height Auto, 취소선.
- 할인율·판매가·정가 사이 간격은 별도 지정이 없어 12px로 적용한다.


## 상품 후기 문구 및 구분선
- 가격 행 아래 18px 간격으로 첫 번째 구분선을 배치한다.
- 구분선: 너비 458px, 두께 1px.
- 구분선과 후기 문구 사이 간격: 18px.
- 후기 문구 3개를 순서대로 배치한다.
  1. `촉촉함이 오래가고 피부결이 매끈해져요.`
  2. `피부가 더 화사해졌어요.`
  3. `가려움 없이 편안하고 보습력이 좋아요.`
- 후기 문구: 25px, 굵기 500 (Medium), Line Height Auto.
- 각 후기 문구 아래에도 동일한 458 × 1px 구분선을 18px 간격으로 배치한다.
- 모바일에서는 구분선 너비를 콘텐츠 영역에 맞추고 텍스트 크기를 반응형으로 조정한다.
