# Notice 서브페이지

## 파일 구성
- HTML: `Biodance/css/notice.html`
- CSS: `Biodance/css/notice.html` 내부 스타일

## 페이지 상단 인트로
- Event 서브페이지와 동일한 제목 그룹 구조와 타이포그래피 사용
- 큰 제목: `Notice`
- 소제목: `공지사항`
- 제목 크기: 42px
- 제목 굵기: 600
- 소제목 크기: 16px
- 소제목 굵기: 400
- 제목과 소제목 사이 간격: 16px
- 가운데 정렬

## 공지사항 목록 헤더
- 소제목 아래 간격: 80px
- 공지, 제목, 작성자 3개 셀을 하나의 `.notice-list-frame` 프레임으로 구성
- 프레임 크기: 1600px × 81px (화면 폭이 좁을 때는 화면에 맞춰 축소)
- 공지 셀: 80px × 81px
- 제목 셀: 남은 너비(기준 1400px) × 81px
- 작성자 셀: 120px × 81px
- 셀 텍스트: 14px, Medium(500)
- 공지와 작성자 텍스트: 가로·세로 가운데 정렬
- 제목 텍스트: 세로 가운데, 왼쪽 정렬
- 제목 텍스트와 셀 왼쪽 프레임 사이 간격: 30px

## 모바일 대응
- 전체 프레임 너비는 화면에 맞게 축소
- 공지 셀 64px, 작성자 셀 82px, 제목 셀은 남은 너비 사용
- 모바일 셀 높이: 64px
- 제목 왼쪽 여백: 14px
