# Global Stores 서브페이지

## 파일 구성
- HTML: `Biodance/css/global-stores.html`
- 문서: `Biodance/css/global-stores.md`

## 페이지 목적
바이오던스를 전 세계에서 만날 수 있는 글로벌 스토어 안내 서브페이지입니다.

## 상단 인트로
Event 페이지의 제목 그룹 구조와 배치를 그대로 사용합니다.
- 큰 제목: `Global Stores`
- 소제목: `바이오던스를 전 세계에서 만나보세요`
- 인트로 영역 높이: 220px
- 상단 여백: 120px
- 제목 크기: 42px
- 제목 굵기: 600
- 소제목 크기: 16px
- 소제목 굵기: 400
- 제목과 소제목 사이 간격: 16px
- 가운데 정렬
- 모바일에서는 Event 페이지와 동일한 반응형 글자 크기를 적용합니다.

## 헤더 메뉴 연결
공통 헤더 파일 `header.html`의 Community 메뉴 안에 있는 링크를 사용합니다.
- Global Stores → `global-stores.html`
- Membership → `membership.html`
- Notice → `notice.html`

## 페이지 콘텐츠
- 지역별 스토어 안내 영역
- 공식몰 안내 영역
- 실제 외부 판매처 URL은 공식 확인 전까지 임의로 연결하지 않습니다.
