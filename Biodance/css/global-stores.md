# Global Stores 서브페이지

## 파일 구성
- HTML: `Biodance/css/global-stores.html`
- 문서: `Biodance/css/global-stores.md`

## 페이지 목적
바이오던스의 글로벌 판매 채널을 안내하는 서브페이지입니다.

## 상단 인트로
- Event 서브페이지와 동일한 제목 그룹 구조 및 배치
- 큰 제목: `Global Stores`
- 소제목: `바이오던스를 전 세계에서 만나보세요`
- 제목 크기: 42px
- 제목 굵기: 600
- 소제목 크기: 16px
- 소제목 굵기: 400
- 제목과 소제목 사이 간격: 16px
- 가운데 정렬

## 메뉴 연결
- 공통 헤더의 Global Stores 메뉴는 `global-stores.html`로 연결합니다.
- 공통 헤더의 Membership 메뉴는 `membership.html`로 연결합니다.
- 공통 헤더의 Notice 메뉴는 `notice.html`로 연결합니다.
- 푸터의 Stores 메뉴는 `global-stores.html`로 연결합니다.

## 참고
지역별 스토어 카드의 실제 외부 판매처 URL은 공식 확인 전까지 임의로 등록하지 않습니다.
