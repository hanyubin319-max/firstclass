# Event 서브페이지

## 파일 구성
- HTML: `Biodance/css/event.html`
- CSS: `Biodance/css/event.css`
- JavaScript: `Biodance/css/event.js`
- 문서: `Biodance/css/event.md`

## 페이지 목적
이벤트 정보를 한곳에서 확인하고 진행 상태에 따라 이벤트 목록을 구분해서 볼 수 있는 서브페이지입니다.

## 상단 인트로
- 인트로 영역 높이: 220px
- 상단 여백: 72px
- 제목: `Event`
- 제목 크기: 42px
- 제목 굵기: 600
- 제목 행간: 100%
- 설명: `공식몰에서만 진행하는 이벤트`
- 설명 크기: 16px
- 설명 굵기: 400
- 설명 행간: 100%
- 제목과 설명 사이 간격: 16px
- 제목과 설명은 가운데 정렬

## 이벤트 필터
상품 서브페이지의 목록 정렬 컨트롤과 동일한 간격 및 디자인 규칙을 따릅니다.

필터 항목:
- 전체
- 진행중
- 종료

## 이벤트 데이터
이벤트 목록은 `event.js`의 `events` 배열에서 관리합니다.
각 이벤트의 `status` 값은 다음 중 하나를 사용합니다.
- `ongoing`: 진행중
- `ended`: 종료

## 연결 규칙
- 공통 헤더의 Event 메뉴는 이 프로젝트 내부의 `event.html`로 연결합니다.
- 외부 공식 사이트로 이동하는 링크는 사용하지 않습니다.
