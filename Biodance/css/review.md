# Review 서브페이지

## 파일 구성
- HTML: `Biodance/css/review.html`
- CSS: `Biodance/css/review.css`
- JavaScript: `Biodance/css/review.js`
- 문서: `Biodance/css/review.md`

※ 현재 작업은 설계 문서 생성 단계입니다. HTML/CSS/JavaScript 파일은 Review 페이지 구현 단계에서 생성합니다.

## 페이지 목적
바이오던스 상품을 사용한 고객의 후기를 한곳에서 확인할 수 있는 서브페이지입니다.

사용자가 다른 고객의 별점, 사용 후기, 사진 등을 살펴보고 상품의 특징과 실제 사용 경험을 파악하여 구매 판단에 참고할 수 있도록 합니다.

## 공통 디자인 및 레이아웃
- 기존 서브페이지와 동일한 공통 헤더 및 푸터를 사용합니다.
- 공통 헤더는 `[data-shared-header]` 영역과 `common-header.js`를 재사용합니다.
- 기본 스타일은 `main.css`, `common-badge.css`, Pretendard Variable을 우선 사용합니다.
- 메인페이지의 브랜드 컬러와 디자인 토큰을 재사용합니다.
- 상단 인트로는 Event 서브페이지의 제목 영역 구성과 정렬 방식을 기준으로 합니다.
- 페이지 제목: `Review`
- 제목 크기: 42px
- 제목 굵기: 600
- 제목 행간: 100%
- 인트로 영역 높이: 220px
- 제목과 보조 설명은 가운데 정렬합니다.
- 보조 설명 문구는 최종 카피 결정 단계에서 확정합니다.

## 리뷰 목록 구성
리뷰 목록은 사용자가 상품 후기의 핵심 정보를 빠르게 파악할 수 있도록 구성합니다.

리뷰 항목에 표시할 정보:
- 별점
- 상품명
- 리뷰 내용
- 작성자 표시명
- 작성일
- 리뷰 이미지(이미지가 등록된 경우)
- 상품 옵션 또는 구매 정보(실제 데이터가 있는 경우)

실제 데이터가 확인되지 않은 구매 인증, 작성자 정보, 리뷰 수치는 사실처럼 표시하지 않습니다. 임시 데이터를 사용할 때는 테스트용 데이터임을 구분합니다.

## 리뷰 목록 상단 정보 및 컨트롤
- 전체 리뷰 개수를 표시합니다.
- 리뷰 정렬 컨트롤을 제공합니다.
- 정렬 기준 후보: 최신순, 평점 높은순, 평점 낮은순
- 포토 리뷰만 보기 기능은 구현 범위를 확정한 뒤 적용합니다.
- 상품별 필터 또는 검색 기능은 필요성과 실제 데이터 구조를 확인한 후 결정합니다.

## 리뷰 데이터 및 동작
- 리뷰 데이터는 구현 단계에서 `review.js`의 데이터 배열로 관리합니다.
- 리뷰 데이터에는 별점, 상품명, 리뷰 내용, 작성자, 작성일, 이미지 정보를 구분하여 저장합니다.
- 정렬 컨트롤을 변경하면 선택한 기준에 맞춰 리뷰 목록을 다시 표시합니다.
- 포토 리뷰 필터를 구현하는 경우 이미지가 있는 리뷰만 표시합니다.
- 리뷰가 많아지면 페이지네이션으로 나누어 표시합니다.
- 페이지네이션은 기존 서브페이지의 공통 `.product-pagination` 스타일을 재사용합니다.
- 페이지네이션 버튼의 Corner Radius는 `9999px`로 유지합니다.
- 필터나 정렬 변경 시 현재 페이지가 1페이지로 초기화되도록 합니다.

## 반응형 기준
- PC와 모바일에서 리뷰 내용과 별점, 상품명이 읽기 쉽게 배치되어야 합니다.
- PC의 가로 배치를 모바일에서 단순히 축소하지 말고 화면 폭에 맞게 재배치합니다.
- 리뷰 이미지가 있는 경우 모바일에서도 이미지 비율이 깨지지 않도록 합니다.
- 버튼과 필터는 모바일에서 터치하기 쉬운 크기와 간격을 유지합니다.
- 기존 공통 헤더의 반응형 동작에 영향을 주지 않습니다.

## 연결 규칙
- 공통 메뉴의 Community 영역에 있는 Review 항목은 프로젝트 내부의 `review.html`로 연결합니다.
- 푸터의 Review 항목도 프로젝트 내부의 `review.html`로 연결합니다.
- 외부 공식 사이트로 이동하는 링크는 사용하지 않습니다.
- 이번 문서 생성 단계에서는 `header.html` 및 다른 페이지의 링크를 수정하지 않습니다.

## 구현 시 주의사항
- `main.css`와 공통 헤더의 기존 디자인을 임의로 변경하지 않습니다.
- 기존 Event, New, 상품 페이지의 레이아웃과 기능에 영향을 주지 않습니다.
- 공통 스타일로 해결할 수 있는 부분은 기존 CSS를 우선 재사용하고, Review 전용 스타일은 `review.css`에 작성합니다.
- 실제 리뷰 데이터가 연결되지 않은 상태에서 실제 고객 후기처럼 보이는 내용을 확정 데이터로 사용하지 않습니다.
- 포토 리뷰 필터, 상품별 필터, 검색, 리뷰 상세 보기 등 추가 기능은 필요성과 구현 범위를 검토한 뒤 결정합니다.
- PC와 모바일에서 정렬, 필터, 페이지네이션 동작을 각각 확인합니다.
